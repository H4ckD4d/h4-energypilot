# Google AI research — optional, public knowledge only

The `scripts/research_public.py` sample can use Gemini Google Search grounding with a user-supplied `GEMINI_API_KEY` to study public domain topics relevant to **H4 EnergyPilot**.

Do not send customer quotes, personal data, private website source, passwords, electrical measurements tied to private facilities, or confidential documents.

Requires optional `pip install google-genai`; availability, pricing and model selection are external and must be checked before use.
