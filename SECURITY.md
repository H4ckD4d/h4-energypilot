# Security / Segurança / Seguridad

**H4 EnergyPilot** is an educational, bounded technical starter. No production deployment or security certification is claimed.

- Report vulnerabilities via private GitHub security advisories, not public issues.
- Do not disclose customer secrets or private URLs in issues.
- The accessibility analyzer processes *supplied* HTML and performs no remote fetch.
- The energy module never controls electrical equipment.
- Quote calculations are estimates, not legal tax invoices.
- Use test data and explicit authorizations only.
